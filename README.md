\# IPL Cricket Analytics



\## Project Overview



IPL Cricket Analytics is a data analytics project exploring Indian Premier League match data to identify patterns in team performance, match outcomes, and factors that influence winning.



The project will use Python, SQL, statistics, and data visualisation techniques for cricket analytics.



\## Business Question



What actually decides an IPL match, and what does that mean for how a franchise should prepare?



\## Dataset



The project contains five tables covering 19 IPL seasons.



The project will use the approved data source provided for this assignment. Raw source data will be kept in the `data/raw` folder and will not be tracked by Git.



Processed data will be stored in the `data/processed` folder.



\## Project Structure



\- `data/raw` - Original source data

\- `data/processed` - Cleaned and processed data

\- `sql/practice` - SQL practice queries

\- `notebooks` - Jupyter notebooks

\- `reports/figures` - Charts and visualisations

\- `dashboard` - Dashboard files
